# Project Goals
Auto-baseline a developer team member at a client Org to assess skill level, claude code usage patterns, identify gaps, and score them on AI Usage Maturity. Individual scores will rollup at the team level to evaluate overall team maturity and readiness for Automating the SDLC using existing and net new AI tooling.

Quantitative scoring and qualitative findings will be derived from Claude Code Logs (commands used, frequency, patterns)
